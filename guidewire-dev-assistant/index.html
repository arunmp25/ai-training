🎤 Say A chat assistant answers questions about your code. A harness works inside your code: it reads files, makes edits and runs the build. Many products use the same model; the harness decides what it can see and do.

  • Ask the room: who has pasted a Gosu class into a chat window and asked “what does this do”? That is the chat model.
  • The last row matters later: in a harness, you control what the agent may do through permissions, not by copy and paste.
  • Guidewire’s Developer Assistants are built for harnesses, not for chat windows.

MCP

What is an MCP server?

The Model Context Protocol is an open standard for plugging tools and knowledge into AI apps. An MCP server is the plug. Click each part.

What a server can offer
⏱ 3 min

🎤 Say An MCP server is a program that offers tools, data and prompt templates in one standard format. Build it once and any MCP-aware harness can use it: Claude Code, Copilot, Cursor or Kiro. That is why Guidewire chose MCP rather than building its own chatbot.

  • Think USB-C: one plug shape for every device.
  • Tools are by far the most used. Resources and prompts are useful for read-only knowledge and ready-made tasks.
  • Without a standard, each vendor would need a plugin for each AI tool: N × M integrations. With MCP it is N + M.

Guidewire Developer Assistant

Guidewire knowledge, delivered as MCP servers

Released in Qusar (August 2026). Each assistant is an MCP server that plugs into the harness you already use.

✅ Generally available

Gosu: code, entities, PCF pages, display keys, tests.
Integrations: Integration Gateway routes, mappings, Java classes from an API file.
Jutro: digital experiences with the right design-system components and UX rules.

🧪 Early access

Developer Assistant for Functions · Product Design Assistant for APD · Data Curation Assistant for Data Studio

What makes them “Guidewire-native” (Guidewire’s four design choices)
  1. Purpose-built for InsuranceSuite: Gosu syntax, PCF structure, Cloud APIs, best practice.
  2. Grounded in Guidewire’s internal docs, cookbooks and curated embeddings, not public web data.
  3. Version-aware: guidance matches your cloud release and project setup.
  4. Delivered through MCP, inside your toolkit, not as a separate chatbot.
⏱ 3 min

🎤 Say Guidewire did not build another chat window. It packaged what a senior Guidewire developer knows (cookbooks, patterns, version rules) as MCP servers. Your harness calls them whenever a task touches Guidewire code, configuration or APIs.

  • Status as of the Qusar release. Gosu was early access back in Niseko. Jutro’s MCP server was early access in Palisades.
  • A cookbook is a curated set of recipes: the right way to do a common Guidewire task, step by step.
  • Version awareness matters: a pattern correct for one release can be an anti-pattern in the next.

Takeaways

What to remember

🧰 Harness, not chat

A harness runs the loop in your repo: it reads, edits, builds and tests. You govern it with permissions.

🔌 MCP is the plug

One standard lets any harness use any server. Tools appear to the model next to the built-in ones.

📖 Guidewire brings the know-how

Developer Assistants supply cookbooks, curated docs and version-aware rules. You keep your tools and your governance.
