The agentic loop

An agent is a model using tools in a loop, deciding its own next step, until the goal is done. That’s the whole idea.

⏱ 30 sec

🎤 Say An agent is a model using tools in a loop, deciding its own next step until the goal is done. That is the whole idea.

  • A common definition: “an LLM using tools in a loop”. Everything else is detail.
Two patterns

Workflow or agent?

Both use AI and tools. The difference is who decides the next step.

⏱ 2 min

🎤 Say Workflow or agent? The difference is who decides the next step: your code or the model.

  • Many “agents” in production are really workflows, and that’s fine. Predictable is good.
  • Use an agent when you can’t write the steps down in advance.

Takeaways

What to remember

🔁 The loop

Plan → act (tool) → observe the result → done? If not, go round again.

🛤️ Workflow vs agent

Fixed steps when you know them; an agent when you don’t. Pick the simplest that works.

🎚️ Dial up gradually

Limits, checkpoints and verification make loops safe.
