# Microsoft 365 Copilot Chat: quick wins

Open `index.html` in a browser. It is a presenter page with twelve short demos that need only **Copilot Chat** (m365copilot.com, the Microsoft 365 Copilot app, or Copilot in Teams), not Copilot inside Word, Excel or Outlook.

- Each quick win has the sample file to upload, prompts with a Copy button, steps, the point to make and the course topic it links to.
- **▶ Present** (or P) shows one quick win at a time for the projector; ← → move, Esc exits. T switches light and dark.
- `samples/` holds the files. All names, policies and numbers are fictional (HarborShield) and safe to upload.
- `M365-quick-wins-files.zip` is the samples folder zipped, to share with attendees before the session.

| File | Used in |
|---|---|
| `1-whiteboard-photo.png` | 1 Whiteboard → action list |
| `2-error-screenshot.png` | 2 Explain an error |
| `3a-motor-policy-2025.pdf`, `3b-motor-policy-2026.pdf` | 3 Spot the changes (eight sections differ), 4 Answer with a citation, 6 Draft the reply, 12 Mini agent |
| `4-customer-complaint-letter.pdf` | 4, 5 Translate and check, 6, 11 Role-play |
| `5-meeting-notes.txt` | 7 Notes → a shared page |
| `6-claims-2026.csv` | 8 Chart claims data |

Copilot features vary by tenant and licence (file upload, Create agent, image creation, Pages). Try each demo in your tenant before the session.
